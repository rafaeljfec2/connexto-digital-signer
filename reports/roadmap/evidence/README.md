# Evidências da Fase 0 (diagnóstico)

Esta pasta guarda **logs e notas de reprodução** dos três defeitos críticos.

- **Não** substitui testes na base de código após correção.
- Artefatos aqui podem ser commitados; **testes vermelhos não** entram na branch principal.

Modelo de arquivo: `inc0-repro-log-YYYY-MM-DD.md` com:

1. Commit ou revisão testada  
2. Comando executado  
3. Saída (falha esperada) por cenário I0-AC1, I0-AC2, I0-AC3  
4. Referência aos critérios em `../04-acceptance-criteria.md`

O primeiro log será produzido na execução da Fase 0 (ainda não gerado nesta revisão de planejamento).
